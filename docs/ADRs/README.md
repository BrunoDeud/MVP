# Registros de Decisão Arquitetural (ADRs)

Estes ADRs descrevem a **versão local simplificada atualmente implementada** do Encontrei — Achados e Perdidos.

| ADR | Decisão atual |
|---|---|
| [ADR-001](ADR-001.md) | Interface em HTML, CSS e JavaScript nativos |
| [ADR-002](ADR-002.md) | Backend em Python com biblioteca padrão |
| [ADR-003](ADR-003.md) | Banco SQLite em arquivo local |
| [ADR-004](ADR-004.md) | Execução local por um único comando |
