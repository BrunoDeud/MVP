# ADR-001 — Interface web com HTML, CSS e JavaScript nativos

- **Status:** Aceita para a versão local simplificada do MVP
- **Data:** 2026-10-22
- **Substitui:** a decisão anterior de utilizar React, Vite, React Router e Tailwind CSS na implementação do MVP.

## Contexto

O projeto Encontrei precisa apresentar os principais fluxos de achados e perdidos em um ambiente acadêmico. A versão original previa uma SPA com React e um processo de build com Vite, mas a configuração de ferramentas adicionais dificultava executar a aplicação em computadores de apresentação. A prioridade desta versão é permitir que a interface seja executada localmente com o mínimo de instalação possível.

## Decisão

Utilizar **HTML, CSS e JavaScript nativos**, concentrados no arquivo `index.html`. O servidor Python entrega essa página ao navegador e também disponibiliza a API local usada pela interface. Não há React, Vite, Tailwind, npm, bundler ou dependências externas de frontend nesta versão.

## Alternativas consideradas

- **React + Vite:** oferece componentes e ferramentas de desenvolvimento, mas exige Node.js, npm e um processo de compilação.
- **Templates renderizados no servidor:** reduziriam a lógica no navegador, mas exigiriam criar um sistema de templates adicional.
- **HTML/CSS/JavaScript nativos:** escolhido por ser a alternativa com menos dependências e mais simples de executar no ambiente da atividade.

## Consequências

### Positivas

- A interface pode ser servida diretamente pelo servidor local, sem etapa de build.
- Menos ferramentas precisam ser instaladas e configuradas no computador de apresentação.
- A comunicação entre a interface e a API usa o mesmo servidor local.

### Negativas

- O arquivo de interface concentra bastante código e é menos modular do que uma aplicação baseada em componentes.
- Não há os recursos de desenvolvimento e otimização fornecidos pelo ecossistema React/Vite.
- Não há PWA nem instalação como aplicativo nativo; essas capacidades ficam fora do escopo desta versão demonstrativa.
