### ADR-001: Escolha do Framework Frontend (React com JavaScript) — Aprovado

**Contexto:** O MVP precisa de interface responsiva e leve em celulares dentro do campus e de possibilidade de instalação como PWA. O acesso é restrito a usuários autenticados, então indexação por buscadores não é requisito. A equipe é pequena e precisa de uma linguagem e de um ecossistema muito difundidos.

**Decisão:** Utilizar React com JavaScript (ES2023), Vite como bundler, React Router para navegação e Tailwind CSS para estilos, empacotado como PWA.

**Consequências:**

- (+) JavaScript é uma das linguagens mais usadas do mundo; React tem a maior comunidade, documentação e oferta de profissionais.
- (+) Por ser uma API REST independente, o frontend se conecta ao backend Laravel (ADR-002) sem acoplamento e pode ser publicado separadamente.
- (+) O build do Vite é rápido e o resultado é um site estático, simples e barato de publicar (RNF02).
- (+) PWA evita o custo de desenvolver app nativo no MVP.
- (−) JavaScript sem tipagem estática permite mais erros em tempo de execução; mitigado com ESLint, JSDoc e testes automatizados (RNF15), e a migração para TypeScript continua possível.
- (−) Uma SPA não é indexada por buscadores, o que é aceitável porque o conteúdo exige login.
- (−) Notificações push no iOS via PWA têm limitações; o MVP depende de e-mail e notificações in-app.
