### Regras de Negócio (RN)

| ID | Regra |
| --- | --- |
| RN01 | Somente e-mails de domínios institucionais cadastrados pelo administrador podem criar conta. |
| RN02 | A conta só fica ativa após verificação do e-mail; o link de verificação expira em 24 horas. |
| RN03 | Todo item achado exige ao menos 1 foto; item perdido pode não ter foto. |
| RN04 | Cada item aceita no máximo 3 fotos, de até 5 MB cada, nos formatos JPG, PNG ou WEBP. |
| RN05 | Todo item achado deve ter ao menos 1 pergunta de verificação (ex.: "Qual o chaveiro preso à mochila?"); a pergunta e a resposta esperada nunca são exibidas publicamente. |
| RN06 | Itens da categoria "Documentos", "Cartões" e "Eletrônicos" devem ser entregues ao ponto de guarda; o anúncio é cadastrado pelo moderador ou com entrega confirmada por ele. |
| RN07 | Um usuário não pode reivindicar item que ele mesmo publicou. |
| RN08 | Um usuário só pode ter uma reivindicação ativa (pendente ou aprovada) por item. |
| RN09 | Um item só pode ter uma reivindicação aprovada por vez; ao aprovar uma, as demais pendentes passam para "Cancelada". |
| RN10 | Uma reivindicação pendente não respondida em 7 dias é encaminhada à fila de moderação. |
| RN11 | Anúncios abertos expiram após 60 dias sem atividade; itens fisicamente guardados seguem a política institucional de descarte/doação (prazo configurável, padrão de 90 dias) após aviso prévio de 7 dias. |
| RN12 | Dados de contato pessoal (e-mail, telefone) nunca são exibidos entre usuários; toda comunicação ocorre pelo canal interno da reivindicação. |
| RN13 | Cada usuário pode publicar no máximo 10 anúncios abertos simultaneamente e 5 anúncios por dia. |
| RN14 | Um anúncio com 3 ou mais denúncias de usuários distintos é ocultado automaticamente até revisão do moderador. |
| RN15 | Toda ação de moderação (remoção, aprovação, banimento) deve registrar autor, data e justificativa. |
| RN16 | Itens resolvidos ou expirados permanecem no banco para histórico, mas não aparecem em buscas públicas. |
| RN17 | A sugestão de correspondência considera mesma categoria, local do mesmo bloco/prédio e data do achado em até 15 dias após a data da perda. |
| RN18 | Usuário com 3 denúncias procedentes é suspenso automaticamente e avaliado por moderador. |
