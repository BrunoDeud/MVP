### Requisitos Funcionais (RF)

| ID | Requisito | Perfil |
| --- | --- | --- |
| RF01 | O sistema deve permitir cadastro e login com e-mail institucional verificado. | Usuário |
| RF02 | O sistema deve permitir publicar um item **achado** com título, categoria, descrição, local, data e até 3 fotos. | Usuário |
| RF03 | O sistema deve permitir publicar um item **perdido** com título, categoria, descrição, local provável, data e até 3 fotos (opcional). | Usuário |
| RF04 | O sistema deve listar itens com busca por texto e filtros por tipo, categoria, local, período e status. | Todos |
| RF05 | O sistema deve exibir a página de detalhes do item, ocultando informações de verificação. | Usuário |
| RF06 | O sistema deve permitir que um usuário solicite a reivindicação de um item achado, respondendo a perguntas de verificação. | Usuário |
| RF07 | O publicador do item achado (ou o moderador, se o item estiver no ponto de guarda) deve poder aprovar ou recusar a reivindicação. | Usuário/Moderador |
| RF08 | O sistema deve permitir trocar mensagens curtas dentro de uma reivindicação aprovada para combinar a entrega, sem expor contato pessoal. | Usuário |
| RF09 | O sistema deve permitir marcar um item como **Devolvido/Resolvido**. | Usuário/Moderador |
| RF10 | O sistema deve enviar notificações por e-mail e in-app para eventos relevantes (nova reivindicação, aprovação, recusa, possível correspondência, expiração). | Sistema |
| RF11 | O sistema deve sugerir possíveis correspondências entre itens perdidos e achados (mesma categoria, local e janela de datas). | Sistema |
| RF12 | O sistema deve permitir denunciar um anúncio ou usuário. | Usuário |
| RF13 | O sistema deve oferecer painel de moderação para tratar denúncias, remover anúncios e registrar a ação. | Moderador |
| RF14 | O sistema deve permitir ao moderador cadastrar itens recebidos no ponto de guarda, vinculando-os a um local de guarda. | Moderador |
| RF15 | O sistema deve expirar automaticamente anúncios após o prazo definido, mantendo o histórico. | Sistema |
| RF16 | O usuário deve poder consultar e gerenciar seus próprios anúncios e reivindicações ("Meus itens"). | Usuário |
| RF17 | O administrador deve poder gerenciar categorias, locais do campus, pontos de guarda e perfis de moderador. | Administrador |
